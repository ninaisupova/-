# Сайт IT-команды — DIGITAL STUDIO

Готовый адаптивный одностраничный сайт на HTML, CSS и JavaScript.

## Как открыть
Распакуйте архив и откройте `index.html` в браузере.

## Что обязательно заменить перед публикацией
1. В `index.html` замените временный бренд `DIGITAL STUDIO` на утверждённое название компании.
2. В `script.js` замените `your-email@example.com` на рабочий адрес для заявок.
3. Добавьте реальные ссылки на Telegram, WhatsApp Business и e-mail, когда они будут готовы. Сейчас контакты не выдуманы и не подставлены.
4. Проверьте описание проекта Platinum Pear и оставьте статус «в разработке», пока он не будет завершён.
5. Добавьте политику обработки персональных данных и согласие на обработку данных, если будете собирать заявки через подключённую серверную форму.

## Публикация
Можно разместить на любом статическом хостинге: GitHub Pages, Netlify, Vercel или обычном хостинге с поддержкой HTML.

Форма сейчас формирует письмо через почтовое приложение посетителя. Для отправки заявок без почтового приложения понадобится подключить серверную обработку формы или сервис форм.
